# AV Workstation Toolkit 1.1.2 (unsigned)

AV Workstation Toolkit is a Windows application for planning, installing, and maintaining a controlled AV/IT workstation software baseline. Version 1.1.2 correctly detects installed AV applications that earlier builds reported as not installed, and names its exact version everywhere. It is built on the `ReleaseCandidate` channel, published under the [unsigned publication procedure](../Packaging-and-Release.md#unsigned-publication), and **not code-signed**.

## Before you install

- **Unsigned.** Windows SmartScreen will show "Windows protected your PC", and an organization's endpoint policy may block the file. Choose **More info > Run anyway** only after verifying the checksum below. Signed releases follow once hosted signing is operational; see the [code signing policy](../Code-Signing-Policy.md).
- **Verify first.** Compare each download with `AV-Workstation-Toolkit-1.1.2-SHA256SUMS.txt` on the release page, for example `Get-FileHash .\AV-Workstation-Toolkit-1.1.2-win-x64.exe`. The release manifest records the exact source commit, build channel, and signature state.
- **Requirements.** Windows 10 or Windows 11 x64, a standard-user session (the app refuses to start elevated), and App Installer/WinGet for managed applications. The download is self-contained; no separate .NET installation is needed.
- **Use on test or pilot workstations** until you have reviewed it against your organization's software policy.

## Upgrading from 1.1.1

- **EXE or ZIP:** close the earlier build and run the 1.1.2 file instead. The window title reads **AV Workstation Toolkit 1.1.2**.
- **MSI:** installing the 1.1.2 MSI replaces an installed 1.1.1 build.
- Your data in `%LOCALAPPDATA%\AVWorkstationToolkit`, including downloaded catalog updates, is kept.

## What's new since 1.1.1

- **Installed applications are detected by the names their installers actually register.** Many applications, Extron Toolbelt among them, showed "Not installed" while installed, because installers register names such as "Extron - Toolbelt", "Extron Electronics - Toolbelt", "BiampCanvas", or "Crestron Device Database200.460.001.00" rather than the bare product name. 60 detectors were corrected and 69 applications gained detection; 105 of the 283 commercial AV applications and all 25 operational external tools can now report installed state. Applications without a known installed name show "Not checked" rather than a guess.
- An installed application whose installer reports no usable version now shows **Installed** with an unknown version instead of "Couldn't check status".
- The window title, About box, diagnostics, and file names carry the exact version, so you can always tell which build is open.
- Bug reports and catalog corrections now have issue forms that warn against posting diagnostics, snapshots, or credentials, and the documentation is reorganized for public readers.

See the [change log](../CHANGELOG.md) for details.

## What it does

- Inventories 30 exact-ID WinGet applications and 25 operational external AV tools, and describes 283 commercial AV applications as non-deployable awareness records.
- Builds a read-only workstation plan before any change, and allows only exact allowlisted WinGet install or update requests, one package at a time, through an independently validating worker with live revalidation and reboot policy.
- **Device Lookup** answers "what software does this device need?" from a signed reference catalog that updates in the app (**Help > Device catalog updates**). This release starts from reference catalog revision 3 (`2026.9.24.1`), covering 79 manufacturers, 533 device models, 270 software products, and 339 documented relationships.
- The managed WinGet catalog is signed separately; the release embeds its signed revision 1.
- Operators who prefer a terminal can plan, install, and update approved applications with the allowlisted command-line scripts in the source repository.
- Diagnostics, logs, credentials, and vendor caches stay on the workstation.

## Known limitations

- Unsigned build: see **Before you install**.
- Installed-state detection covers applications whose installed name has been confirmed. If an installed application still shows "Not installed" or "Not checked", please report the name it shows in Windows **Settings > Apps > Installed apps**.
- Device Lookup uses the signed reference catalog. Official-page corrections made in source after revision 3 reach Device Lookup when reference catalog revision 4 is published; the Software table already includes them.
- The in-app managed-catalog update check has no published feed yet, so the embedded signed revision 1 remains in use.
- The package QA desktop smoke test and interactive UI review depend on a real desktop session; their status is listed on the release page.
- Uninstalling the MSI intentionally keeps `%LOCALAPPDATA%\AVWorkstationToolkit`.
