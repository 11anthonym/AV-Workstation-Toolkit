# AV Workstation Toolkit 1.1.3 (unsigned)

AV Workstation Toolkit is a Windows application for planning, installing, and maintaining a controlled AV/IT workstation software baseline. Version 1.1.3 carries a workstation's applications to its replacement, sets workstations up from reusable workstation templates, and makes installs and updates finish reliably when apps are open or WinGet has a passing problem. It is **not code-signed**.

## Before you install

- **Unsigned.** Windows SmartScreen will show "Windows protected your PC", and an organization's endpoint policy may block the file. Choose **More info > Run anyway** only after verifying the checksum below. See the [code signing policy](../Code-Signing-Policy.md).
- **Verify first.** Compare each download with `AV-Workstation-Toolkit-1.1.3-SHA256SUMS.txt` on the release page, for example `Get-FileHash .\AV-Workstation-Toolkit-1.1.3-win-x64.exe`. The release manifest records the exact source commit and signature state.
- **Requirements.** Windows 10 or Windows 11 x64, a standard-user session (the app refuses to start elevated), and App Installer/WinGet for managed applications. The download is self-contained; no separate .NET installation is needed.
- **Use on test or pilot workstations** until you have reviewed it against your organization's software policy.

## Upgrading from 1.1.2

- **EXE or ZIP:** close the earlier build and run the 1.1.3 file instead. The window title reads **AV Workstation Toolkit 1.1.3**.
- **MSI:** installing the 1.1.3 MSI replaces an installed 1.1.2 build.
- Your data in `%LOCALAPPDATA%\AVWorkstationToolkit`, including downloaded catalog updates, is kept.

## What's new since 1.1.2

- **Workstation migration.** On an old workstation, **Workstation migration** scans and exports a portable inventory of every application Windows registers, including AV software that no package manager knows. On the replacement, importing it gives one checklist of what's installed, what the Toolkit can install automatically, and what you install yourself. The checklist is saved, survives closing the window and restarting the app, and an app leaves it only when a scan detects it. **Finish migration** ends it and uninstalls nothing. See [Workstation migration and templates](../Workstation-Migration-and-Templates.md).
- **Workstation templates.** Define a reusable baseline of required and optional applications and manual checks, and set a workstation up from it. A newer revision keeps progress on the items it retains.
- **Open apps no longer make updates fail.** Some installers stop when their app is running; ShareX failed on every update while it sat in the notification area. Before a run, the Toolkit names the selected apps that are open and offers **Close apps and continue**, **Skip open apps**, or **Cancel**. With your consent it asks each app to close the way Windows does at sign-out, never forcing it, runs the installer, and lets Windows reopen apps that support it. An app that stays open is reported as **In use** and its installer doesn't run.
- **One problem no longer stops a run.** A package that can't run now (a pending restart, an app in use, a hold) is skipped with a plain reason and the rest continue. An app that is already current is reported as **Already current**. A failed download, lost network, or another installation in progress is retried up to twice after a pause; other WinGet failures get a plain explanation. A run where nothing failed but apps were held back ends as **Needs attention**. Installers that need a restart to finish are reported as **Restart required**.
- **Confirm system changes when a run starts.** Apps that install a driver, service, or network listener are confirmed in one **Confirm system changes** dialog that names each app, instead of a check box that cleared itself during a run.
- **Faster multi-app runs.** Each app is still rechecked right before it installs, but a 15-app update spends about 80 seconds less reading workstation state.
- **Crestron MasterInstaller downloads MasterInstaller.** With your own Crestron account, the MasterInstaller row downloads the catalogued MasterInstaller 4.00.11 installer from Crestron SFTP and accepts it only if its hash and Crestron's signature match. The seven Crestron component rows still download from Crestron's product feed.
- **Install results are kept when the check afterward fails.** An app whose installer succeeded but that no scan has detected yet reads **Installed · not verified** instead of **Install failed**.
- **Security update.** The embedded .NET runtime is 10.0.12, the 2026-09-08 .NET 10 security release.

See the [change log](../CHANGELOG.md) for details.

## What it does

- Inventories 30 exact-ID WinGet applications and 25 operational external AV tools, and describes 283 commercial AV applications as non-deployable awareness records.
- Builds a read-only workstation plan before any change, and allows only exact allowlisted WinGet install or update requests, one package at a time, through an independently validating worker with live revalidation and reboot policy.
- **Device Lookup** answers "what software does this device need?" from a signed reference catalog that updates in the app (**Help > Device catalog updates**). This release starts from reference catalog revision 3 (`2026.9.24.1`), covering 79 manufacturers, 533 device models, 270 software products, and 339 documented relationships.
- The managed WinGet catalog is signed separately; the release embeds its signed revision 1.
- Imported inventories and templates never install anything on their own; installs go only through the approved catalog. Open apps are closed only with your consent and never forced. There is no uninstall, command runner, or local web server.
- Diagnostics, logs, credentials, migration checklists, and vendor caches stay on the workstation.

## Known limitations

- Unsigned build: see **Before you install**.
- Installed-state detection covers applications whose installed name has been confirmed. If an installed application still shows "Not installed" or "Not checked", please report the name it shows in Windows **Settings > Apps > Installed apps**.
- Chrome isn't detected as open before its update. WinGet's "restart to finish" notice is recognized only when WinGet runs in English.
- The Crestron MasterInstaller download is version 4.00.11.
- Some official product links in Device Lookup are corrected in the next device catalog update; the Software table already shows the corrected links.
- Managed application catalog updates aren't published yet, so the app uses the catalog it ships with.
- Uninstalling the MSI intentionally keeps `%LOCALAPPDATA%\AVWorkstationToolkit`.
