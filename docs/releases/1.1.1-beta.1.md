# AV Workstation Toolkit 1.1.1 Beta 1 (unsigned)

This is the first public release of AV Workstation Toolkit: a Windows application for planning, installing, and maintaining a controlled AV/IT workstation software baseline. It is a **beta**. It is built on the `ReleaseCandidate` channel, published under the [beta publication procedure](../Packaging-and-Release.md#beta-publication), and **not code-signed**.

## Before you install

- **Unsigned.** Windows SmartScreen will show "Windows protected your PC", and an organization's endpoint policy may block the file. Choose **More info > Run anyway** only after verifying the checksum below. Signed production releases follow once hosted signing is operational; see the [code signing policy](../Code-Signing-Policy.md).
- **Verify first.** Compare each download with `AV-Workstation-Toolkit-1.1.1-SHA256SUMS.txt` on the release page, for example `Get-FileHash .\AV-Workstation-Toolkit-1.1.1-win-x64.exe`. The release manifest records the exact source commit, build channel, and signature state.
- **Requirements.** Windows 10 or Windows 11 x64, a standard-user session (the app refuses to start elevated), and App Installer/WinGet for managed applications. The download is self-contained; no separate .NET installation is needed.
- **Use on test or pilot workstations** until you have reviewed it against your organization's software policy.

## What it does

- Inventories 30 exact-ID WinGet applications and 25 operational external AV tools, and describes 283 commercial AV applications as non-deployable awareness records.
- Builds a read-only workstation plan before any change, and allows only exact allowlisted WinGet install or update requests, one package at a time, through an independently validating worker with live revalidation and reboot policy.
- **Device Lookup** answers "what software does this device need?" from a signed reference catalog that updates in the app (**Help > Device catalog updates**). This beta starts from reference catalog revision 3 (`2026.9.24.1`), covering 79 manufacturers, 533 device models, 270 software products, and 339 documented relationships.
- The managed WinGet catalog is signed separately and updates in the app (**Help > Managed app catalog updates**).
- Diagnostics, logs, credentials, and vendor caches stay on the workstation.

## Recent changes in this build

- Every product opens one verified official product page from the Software table and from Device Lookup. For example, Extron PCS now opens its current product page everywhere, including its vendor-page handoff.
- Device detail pages list every model a software relationship covers, and reference-only software such as RDL Console appears in Device Lookup searches.
- Reference catalog revisions 2 and 3 added RDL DD-RN31, Key Digital KD-MS8x8G-2, and corrected links and lifecycle states from a 440-URL catalog audit.

See the [change log](../CHANGELOG.md) for details.

## Known limitations

- Unsigned build: see **Before you install**.
- Device Lookup uses the signed reference catalog. Official-page corrections made in source after revision 3 reach Device Lookup when reference catalog revision 4 is published; the Software table already includes them.
- The package QA desktop smoke test and interactive UI review depend on a real desktop session; their status is listed on the release page.
- Uninstalling the MSI intentionally keeps `%LOCALAPPDATA%\AVWorkstationToolkit`.
