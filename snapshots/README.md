# Local Snapshot Evidence

Snapshot folders, ZIP archives, and checksum files are intentionally ignored by Git because they may contain workstation, user, path, application, and network metadata.

Keep evidence in this local directory or an approved restricted evidence store.
Do not commit it to the reusable repository or identify a personal workstation
as the product baseline. Record snapshot names and checksums in the external
change record without copying sensitive raw contents into product documentation.
