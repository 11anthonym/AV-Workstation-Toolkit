# AV Workstation Toolkit artwork

`AVWorkstationToolkit.png` is the canonical transparent 1024 px application
mark. `AVWorkstationToolkit.ico` is the derived multi-resolution Windows icon
used by the compiled WPF windows, standalone executable, Start-menu shortcut,
and Installed Apps entry.

The mark was created specifically for AV Workstation Toolkit in September 2026
using OpenAI image generation. It depicts one continuous blue-to-cyan AV signal
path on the project's navy application tile. Do not substitute catalogued vendor
artwork or third-party product branding for the application identity.

The ICO contains 16, 20, 24, 32, 40, 48, 64, 128, and 256 px frames derived
from the PNG master.
